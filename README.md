# ⚖️ Justice – Professional Law Firm Landing Page  
A modern, elegant, and fully responsive **landing page** designed for law firms, created using **HTML**, **CSS**, **Tailwind CSS**, and **DaisyUI**.  
This project focuses on clean structure, smooth layout, and professional UI—built completely without JavaScript.

---

## 🏛️ Overview  
**Justice** is a professional landing page crafted for general law firms targeting individual clients.  
The design highlights clarity, trust, and professionalism—key qualities for legal service branding.

This is **not a full website**, but a single-page landing layout built using modern frontend tools.  
There is **no JavaScript**, making the page lightweight and highly optimized.
